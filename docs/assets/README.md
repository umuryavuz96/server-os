# Screenshots and clips

Everything here comes from **demo mode** (`SERVER_OS_DEMO=1`): a made-up "homelab" with fake apps, vitals, jobs and alerts. No real machine data. Desktop shots are 1440×900 dark theme, phone shots 390×844 at 2× density.

## Clips (`motion/`)

Each clip comes as an MP4 (H.264, 30 fps) and a GIF (960 px, 15 fps) for places that only show images.

| File | What it shows |
|---|---|
| `motion/vitals.mp4`, `.gif` | Live vitals: gauges and sparklines drifting in real time |
| `motion/toggle.mp4`, `.gif` | Stopping and starting Jellyfin from the app drawer, each behind a confirm dialog |
| `motion/jobs.mp4`, `.gif` | Running the `backup-photos` job: status flips to running, the log streams in, status returns to OK |
| `motion/install.mp4`, `.gif` | Searching Discover for FreshRSS and installing it, step by step, until it is ready |
